- `Alt + Shift + 7`:  调用Find usages 

- `Ctrl + Alt + Home`: Navigate between Rails entities

- 按`shift`两次, 输入 `/url/`, 可以查看rails项目的所有路由

- 按`shift`两次, 输入 `/`, 可以直接进行IDE的选项配置

- 按`shift`两次, 可以输入表达式求值

- 点击菜单 `Git | Share Project on GitHub`, 可以把当前项目直接上传到github上

- 在editor中, 按 `ctrl + Shift + F12`, 最大化当前的编辑器窗口

- 按 `esc`, 焦点从任何窗口移到编辑器窗口

- 按 `ctrl + shift + i`, 打开一个弹出窗口查看当前符号的定义

- 按 `ctrl + q`, 浏览一个符号的文档，在按 `ctrl + q`, 会打开文档工具窗口

- 按 `alt + q`, 查看当前方法或类的声明

- 按 `ctrl` 两次, 输入 `rails g controller`, 会打开`Add New Controller`对话框, 其他的
  rails generate命令也类似

- 在一个已打开的文件, 按 `alt + shift + 1`, 会打开 `Select in` 窗口

- 在一个已打开的文件, 按 `ctrl + alt + shift + 2`, 会打开包含该文件的文件管理器 

- 按 `ctrl + e`, 打开 `Recent Files`对话框, 在按一次 `ctrl + e`, 只显示最近编辑过的文件

- 按 `ctrl + shift + e`, 打开 `Recent locations` 窗口,  在按一次 `ctrl + shift + e`,
  只显示最近编辑过的位置, 要搜索代码, 在这个对话框中, 直接敲要检索的单词, 可以检索代码，文件名等

- 按 `alt + shift + c`, 打开 `Recent changes` 窗口

- 在一个打开的文件中, 按 `ctrl + alt + shift + u`, 打开 `diagram` 窗口

- 在编辑器中，把caret放置到类名上，按 `ctrl + h`, 打开 `Type Hierarchy` 窗口

- 在编辑器中，把caret放置到方法名上, 按 `ctrl + alt + h`, 打开 `Call Hierarchy` 窗口

- 在一个打开的文件中, 按 `alt + 7`, 打开 `Structure` tool

- 在编辑器中选中多行，按 `ctrl + f`, 点击过滤器那个图标, 设置 `Search In Selection`, 检索将
  在这些选中的行中搜索

- 在菜单 `Edit | Find | Search Structurally`, 可以按照语法结构进行搜索

- In the Database tool window, select objects in which you want to perform your search. 
  You can select a database or a group of databases, a scheme or schemes, or even 
  separate tables, Right-click the selection and select `Tools | Full-Text Search`
  In the search field of the Full-text Search dialog, type your search request and click Search.

- In the Project tool window, select the files you want to compare and choose 
  `Compare Files`, or select one file, choose `Compare With…` from its context menu

- 按 `ctrl + alt + shift + insert`, 可以创建 `scratch file`, 用于输入一些实验性质的代码,
  也可以在当前打开的文件中, 选中一段代码, 按 `alt + enter`, 选择 `Create new scratch file from selection`
